## Technical requirements

- Astro native: `.astro` components, content collections (blog, stores, brands if any), typed props, no `set:html` of captured markup, no `src/content/*.html` dumps. Static output (`output: 'static'`), Cloudflare Pages target.
- CSS: one small hand-written stylesheet set (tokens, base, components) scoped in Astro components; no framework, no WordPress/theme CSS, no pruning pipeline. Target: home page CSS under 30 KB uncompressed, JS under 10 KB.
- JavaScript: vanilla only, no jQuery. Needed: mobile navigation (prefer `<details>`/popover/`:target` first), the click-to-load embeds, the hero video helper (`prefers-reduced-motion` respected, muted, `playsinline`, plays without a click in Safari; keep the lessons of d25/d26 in `.working-files/hero-video/notes.md`). No slider.
- Images: use `astro:assets` (`<Image>`/`<Picture>`) from a curated `src/assets/` set (only images the new pages use, copied from `.conversion/media-cache`, with alt text from the capture or written plainly); AVIF/WebP with width/height set, `loading="lazy"` below the fold, the LCP image `fetchpriority="high"`. Original uploads are not shipped: the 1.1 GB `/wp-content/uploads/` tree goes away, so old image URLs need no redirect (they were not content URLs) unless a page's `og:image` was indexed: list those.
- Hero video: the downloaded `VidOne.mp4` is HEVC and 26.55 MiB, over the 25 MiB Cloudflare Pages limit. Produce an H.264 (`avc1`), faststart, no audio, under 20 MiB version with the macOS system tool `/usr/bin/avconvert` (do not install anything; try its presets, check codec and moov position by reading the file's atoms, as `.working-files/hero-video/notes.md` shows) and a poster JPEG/AVIF; if `avconvert` cannot reach the target, ship the poster only, say so, and leave the video out of `dist/`. Never commit a file over 25 MiB.
- Security headers in `public/_headers` and a CSP without third parties: `default-src 'self'`; `frame-src` only the three embed hosts (etermin.net, google.com/maps, jobrad calculator host); `img-src 'self' data:`; `X-Robots-Tag: noindex` on `https://bike-one.dev/*` and `*.pages.dev`; `Referrer-Policy`, `X-Content-Type-Options`, `Permissions-Policy` (camera, microphone, geolocation off).
- Dev versus production: keep `INDEXABLE` (`PUBLIC_INDEXABLE=true` only on the launch build), `SHOP_URL`, and the origin handling from the bike-one-links work: canonical, OG, sitemap and feed URLs use the build origin (`https://bike-one.dev` by default, `SITE_ORIGIN` override, `https://bike-one.org` in the release build). A dev build contains no `bike-one.org` string anywhere.
- SEO (inputs: `seo-review.md`): unique title (30 to 60 characters) and meta description (70 to 160) per page, written from the page's own captured text, German; one `h1`; canonical; `lang="de"`; Open Graph and Twitter cards with a 1200x630 image; JSON-LD: `BikeStore`/`LocalBusiness` for both stores using only the facts in the captured footer/Impressum/über-uns (no geo, no ratings, no invented hours), `Organization`, `BreadcrumbList`, `Article` for posts, `WebSite`; internal links between related pages (home to service to booking to blog); native `sitemap` and `robots.txt` (dev: Disallow all; release: Allow + sitemap line); native RSS.
- Accessibility: landmarks, skip link, visible focus, 4.5:1 contrast, labelled controls, `prefers-reduced-motion`, keyboard-operable nav and embed buttons, meaningful `alt`.

## Checks that replace the parity gates

The kit gates (`scripts/verify/*`, `baseline/`) compared against live and will fail by design. Keep what is still meaningful and replace the rest, in `tools/` and `npm run verify` (update `package.json`, `docs/`, `AGENTS.md` and `CLAUDE.md` of `website/` to say so; `baseline/` and `capture/` stay untouched until Stage 4):

- `redirects`: every old URL in `baseline/routes.json` (and `redirects.csv`) resolves in at most one hop to a built page or the shop; no built page sits at a redirect source.
- `links`: every internal link and asset reference in `dist/` resolves to a built file; `mailto:`/`tel:` allowed; no link to `bike-one.org` in a dev build.
- `seo`: the rules in "SEO" above, checked on `dist/` (title/description length and uniqueness, single h1, canonical on the build origin, JSON-LD parses, sitemap lists exactly the indexable pages, no `noindex` page in the sitemap, dev build is `noindex` everywhere).
- `wp`: fails if `dist/` or `src/` contains `wp-content`, `wp-includes`, `wp-json`, `wp-`, `woocommerce`, `yith`, `vc_`, `revslider`, `elementor`, `jquery`, `xmlrpc`, `wlwmanifest`, or the strings `generator` WordPress/WooCommerce (allowlist: redirect sources in `redirects.csv` and `docs/`).
- `net`: Playwright (system Chrome `channel: 'chrome'` and WebKit from `/Users/timo.alts/dev/astro-conversion-kit/node_modules/playwright`): load every built page at 1440 and 390 from the review server, scroll, open the menu, and fail on any request to a non-local host, any 4xx/5xx, any console error or page error. Embeds stay unclicked.
- `size`: no file in `dist/` over 20 MiB, home page transfer budget printed.
- `a11y` smoke: heading order, alt present, labels present (no new dependency; a small script over the HTML is enough).

## Stages (one feature engineer per stage, in order; the main session reviews between stages)

**Stage 1: foundation and one vertical slice.** Finish only after the bike-one-links agent has committed. Create the design tokens, `Base`/`Header`/`Footer`/`SEO` components, fonts, the new check scripts (`redirects`, `links`, `seo`, `wp`, `net`, `size`, `a11y`) wired into `npm run verify`, the redirect map and its generator (reuse `scripts/build-redirects.mjs` if it still fits), the content collections, and migrate **home, über uns, impressum, datenschutz** natively as the slice that proves the pipeline. Exit: the slice passes the new checks (the checks tolerate pages still on the old route only via an explicit, shrinking allowlist in `tools/` that Stage 2 empties), notes-stage1.md, commits.

**Stage 2: all remaining pages.** Termin buchen (three pages, click-to-load embeds), blog index and the 5 posts (collection, RSS), service page from `/main-bike/`, stellenangebote, brand pages or redirects per the IA table, the hero (video helper, poster, H.264 file or poster only), all redirects, native sitemap and robots, 404 page. Exit: the old route and the allowlist are gone; every page is native; all checks pass on dev and release builds (`PUBLIC_INDEXABLE=true`); notes-stage2.md.

**Stage 3: SEO, accessibility, performance pass.** Titles and descriptions reviewed against `seo-review.md`, JSON-LD complete and validated by parsing, OG images, internal linking, heading structure, contrast, keyboard use, image sizes, font preload, CSS/JS budgets, security headers and CSP verified in the network test, console clean on all pages; a visual review of every page at 390, 768 and 1440 with Playwright screenshots into `review/` (not committed) read by the agent (look at them, list defects, fix them). Exit: notes-stage3.md with the measured numbers (bytes per page, requests per page, LCP candidate) and the remaining defects.

**Stage 4: delete WordPress and clean the repository.** Remove `public/wp-content`, `public/wp-includes`, `src/content/{pages,heads,bottoms,parts}`, `tools/extract.mjs`, `tools/strip-sourcemaps.mjs`, the css/coverage/prune/media/assets/baseline-building scripts and any npm scripts that only served the parity pipeline; the kit's `scripts/verify/*` that are replaced; WordPress notes in docs. Keep: `redirects.csv` and its generator, the new checks, `capture/` and `baseline/` only if the redirect check still reads `baseline/routes.json` (preferred: freeze the old-URL list into `docs/old-urls.json` or `redirects.csv` and delete `capture/`, `baseline/`, `.conversion/media-cache` references; the history keeps them, say how to restore). Make `npm run wp` pass with no allowlist beyond redirect sources. Update `website/AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/plan.md` (how the site is built now), `docs/LAUNCH.md` (Cloudflare Pages project, custom domain `bike-one.dev`, `PUBLIC_INDEXABLE` only on the launch build, DNS, redirects, the `?p=` Single Redirects, Search Console), and write `docs/redesign.md` (IA table with the final mapping, decisions, open questions). Exit: repo size before/after, all checks green on dev and release builds, no `wp-` strings, notes-stage4.md.
