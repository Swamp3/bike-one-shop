# Working files

Temporary files for features that are in progress: implementation plans,
notes, analyses, checklists. One folder per feature
(`.working-files/<feature-slug>/`). Delete a feature's folder once it is
done and its lasting decisions are in `planning/` or `PLAN.md`.

This is not documentation. Rules: "Working files vs. documentation" in the
root `CLAUDE.md`. No secrets or personal data here.
